How the system fits together

Public product model from sota.tech. The cycle is ideate, then produce, then optimise. That cycle runs on a stack of models, context, workflows, and applications. Teams use it for product content, localisation, testing, and automation.

The cycle

  • Ideate: find the visual that should exist.
  • Produce: make it on-brand, at volume.
  • Optimise: learn what worked, then do it again.

The stack

  • Models: the visual intelligence.
  • Context: brand, product, customer.
  • Workflows: how a job moves through.
  • Applications: where teams run it.
